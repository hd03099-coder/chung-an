청안부적 홈페이지 파일 안내

- index.html : 홈페이지 첫 화면 및 모든 섹션
- assets/ : 업로드해 주신 이미지를 웹용 WebP로 최적화한 파일

미리보기:
index.html 파일을 Chrome 등 웹브라우저에서 열면 됩니다.
